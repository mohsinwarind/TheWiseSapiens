Since the dawn of transformers, which are sequential neural networks, we humans are witnessing a new kind of revolution where almost every other sector is suffering from recession. However, in reality, or under the hood, these ChatGPT or Claude Agents etc. are nothing but complex matrix multiplication which adjust their weights by training themselves on the existing data. I know it will be hard to gulp down all of these facts at once, therefore, I will try to break it down into chunks to understand it more intuitively. Also, for simplification and some taste of both Machine Learning and Deep Learning, I'm going to apply gradient descent on logistic regression , however, this doesn't mean that the complex self-attention based neural networks works the same way, the main goal is to just give you a low level understanding of how these complex system learn and improve themselves overtime with data.

Thus, before any formal yapping, we need to know that we will be working on supervised machine learning, which means that we are going to have our training data and target sample. For example, the grades of the student as x and the output y as the remarks that they either pass or fail - or binary classification, specifically. Also, in order to understand this supervised machine learning, there is a hack which I always keep in mind, which is to consider an ML algorithm as someone who is dumb as hell. Consider it naive and unbeknownst to everything, not every time, because we have some pretrained ML models with state-of-the-art results, however, if you are planning to train a model from scratch, then it literally knows nothing and just like a kid, you have to invest hell lot of energy and study to educate him or her , same goes with these models because you need extensive computation power and massive dataset to train them. Therefore, our given workflow will be something like this (just skim it please even if it does not make any sense , for now) :

  1. Initialize parameters \[ w=random(),\quad b=random() \]
  2. Calculate linear output \[ z=wx+b \]
  3. Apply Sigmoid \[ \hat y=\frac{1}{1+e^{-z}} \]
  4. Calculate Binary Cross-Entropy \[ BCE=-\frac1n\sum [y\log\hat y+(1-y)\log(1-\hat y)] \]
  5. Calculate gradients \[ dw=\frac1n\sum(\hat y-y)x \] \[ db=\frac1n\sum(\hat y-y) \]
  6. Update parameters \[ w=w-\alpha dw \] \[ b=b-\alpha db \]

Going to repeat this until it converges or the stopping condition is reached.

So guys you might be wondering ,

What the hell are these parameters?

Since we are working on Logistic Regression, which is a modified form of Linear Regression, and linear regression is nothing but slope into variable, added by y-intercept. Mathematically it's represented as: \[ y=mx+b \] Here these \(m\) & \(b\) are the parameters that we are going to learn by our data because the input \(x\) will be multiplied by them to give us the precise output \(y\) we desired, thus again, its nothing but multiplication

You must be familiar with this equation if you studied maths in your college years; however, for Machine Learning we will tweak it a bit like this: \[ y=wx+b \]

Where:

  • \(w\) is going to be the weight we modify, which refers to the slope of the line.
  • \(x\) is the input variable which varies according to each instance.
  • \(b\) is the bias, which forces the decision boundary to shift away from the origin.

Sigmoid: the caveat

If you ever had any experience with Neural Networks, you would be aware of or familiar with Sigmoid as an activation function. However, the use case in classical and deep learning for it is fundamentally different. There, in deep learning, you are going to use it for binary or multi-class classification in the last layer or in hidden layers, but that's not recommended due to certain circumstances. However, here in classical Machine Learning, this activation function serves the same purpose of giving us the output in a certain 0 to 1 range to make it easy for prediction. To be specific, the equation \[ y=wx+b \] is going to give an output of any range; it can be positive or negative, but we know that the probability can only be positive and between 0 and 1 (here 1 means 100), thus to have our desired output we pass the output through the activation function \(z\), where \(z\) is: \[ z =\frac{1}{1+e^{-y}} \] or, being straightforward: \[ \hat y=\frac{1}{1+e^{-(wx+b)}} \]

The Loss function

Another thing that you need to remember is that the loss function you need to use for any specific task can vary with the nature of our target variable. For instance, if you have any regression task, the loss function is going to be Mean Square Error (MSE); however, if you have a classification task, then it will be Cross Entropy loss. But since we are working on the most simplified problem to make it easy to understand the backend, I'm going to use the Binary Cross Entropy loss function because the \(\hat y\) (output) in our equation is going to be binary. So the equation for it will be: \[ \boxed{ BCE=-\frac{1}{n}\sum_{i=1}^{n} [y_i\log(\hat y_i)+(1-y_i)\log(1-\hat y_i)] } \]

Don't get intimidated by this formula ,let me break it down for you :

  • \(n\): Number of observations.
  • \(y_i\): Actual class (0 or 1).
  • \(\hat y_i\): Predicted probability.
  • \(\log\): Natural logarithm (logarithm with base \(e\)).

This equation is going to provide us a penalty which we will use to backpropagate by gradient descent to adjust the weights. Please hold on if you are unable to understand everything, good things take time ;)

Derivatives for Backpropagation

Since we are going to backpropagate, we need partial derivatives beforehand of our equations with respect to \(\hat y\). Let's start with our loss function: \[ L=-[y\log(\hat y)+(1-y)\log(1-\hat y)] \]

Differentiating both terms independently: \[ \frac{\partial L}{\partial \hat y} = -y\frac{1}{\hat y} -(1-y)\frac{1}{1-\hat y}(-1) \]

Simplifying: \[ = -\frac{y}{\hat y} + \frac{1-y}{1-\hat y} \]

Taking the common denominator: \[ = \frac{-y(1-\hat y)+\hat y(1-y)} {\hat y(1-\hat y)} \]

Expanding the numerator: \[ = \frac{-y+y\hat y+\hat y-y\hat y} {\hat y(1-\hat y)} \]

Therefore: \[ \boxed{ \frac{\partial L}{\partial \hat y} = \frac{\hat y-y}{\hat y(1-\hat y)} } \]

For the sigmoid function \[ \sigma(z)=\frac{1}{1+e^{-z}} \]

Differentiating with respect to \(z\): \[ \frac{\partial \sigma(z)}{\partial z} = -\left(1+e^{-z}\right)^{-2}(-e^{-z}) \]

Simplifying: \[ = \frac{e^{-z}}{(1+e^{-z})^2} \] \[ = \frac{1}{1+e^{-z}} \times \frac{(1+e^{-z})-1}{1+e^{-z}} \]

Expand the numerator: \[ = \frac{1}{1+e^{-z}} \times \frac{1+e^{-z}-1}{1+e^{-z}} \]

Rearrange the numerator: \[ = \frac{1}{1+e^{-z}} \times \frac{1-1+e^{-z}}{1+e^{-z}} \]

Since \(1-1=0\): \[ = \frac{1}{1+e^{-z}} \times \frac{0+e^{-z}}{1+e^{-z}} \] \[ = \frac{1}{1+e^{-z}} \times \frac{e^{-z}}{1+e^{-z}} \]

Now substitute: \[ \sigma(z)=\frac{1}{1+e^{-z}} \]

And: \[ 1-\sigma(z)=\frac{e^{-z}}{1+e^{-z}} \]

Because if we try to substitute the sigmoid function: \[ =1-\frac{1}{1+e^{-z}} \]

Take the common denominator: \[ =\frac{1}{1}-\frac{1}{1+e^{-z}} \] \[ =\frac{1+e^{-z}}{1+e^{-z}}-\frac{1}{1+e^{-z}} \]

Combine the fractions: \[ =\frac{(1+e^{-z})-1}{1+e^{-z}} \]

Expand the numerator: \[ =\frac{1+e^{-z}-1}{1+e^{-z}} \]

Rearrange: \[ =\frac{1-1+e^{-z}}{1+e^{-z}} \]

Simplify: \[ =\frac{0+e^{-z}}{1+e^{-z}} \]

Therefore: \[ \boxed{ 1-\sigma(z)=\frac{e^{-z}}{1+e^{-z}} } \]

We can rewrite the derivative as: \[ \boxed{ \frac{\partial \sigma(z)}{\partial z} = \sigma(z)(1-\sigma(z)) } \]

PS: The derivative of sigmoid is simply its output multiplied by one minus its output.

Understanding derivatives in Logistic Regression

Now we need to understand how Gradient Descent will adjust our weight and bias.

Remember our model: \[ z=wx+b \] \[ \hat y=\sigma(z) \]

And our loss function: \[ L=-[y\log(\hat y)+(1-y)\log(1-\hat y)] \]

We need to calculate two derivatives: \[ \frac{\partial BCE}{\partial w} \qquad \frac{\partial BCE}{\partial b} \]

This is where the Chain Rule becomes important.

First, understand the derivative of Sigmoid

Our Sigmoid function is: \[ \sigma(z)=\frac{1}{1+e^{-z}} \]

Its derivative is: \[ \boxed{ \sigma'(z)=\sigma(z)(1-\sigma(z)) } \]

Since \(\hat y=\sigma(z)\), we can also write: \[ \boxed{ \frac{d\hat y}{dz}=\hat y(1-\hat y) } \]

This tells us how the predicted probability changes when the linear combination \(z\) changes.

Deriving the loss derivative

We have BCE as \[ L=-[y\log(\hat y)+(1-y)\log(1-\hat y)] \]

And its derivative as: \[ = \frac{\hat y-y}{\hat y(1-\hat y)} \]

Now apply the Chain Rule: \[ \frac{\partial L}{\partial z} = \frac{\partial L}{\partial \hat y} \times \frac{\partial \hat y}{\partial z} \]

Substituting the derivatives: \[ = \frac{\hat y-y}{\hat y(1-\hat y)} \times \hat y(1-\hat y) \]

Notice something beautiful!

The sigmoid terms cancel each other.

We are left with: \[ \boxed{ \frac{\partial L}{\partial z}=\hat y-y } \]

This is one of the most important mathematical results in Logistic Regression.

Derivative with respect to weight

We know: \[ z=wx+b \]

Therefore: \[ \frac{\partial z}{\partial w}=x \]

Using the Chain Rule: \[ \frac{\partial L}{\partial w} = \frac{\partial L}{\partial z} \times \frac{\partial z}{\partial w} \]

Thus: \[ \boxed{ \frac{\partial L}{\partial w} =(\hat y-y)x } \]

For the entire dataset, we calculate the average: \[ \frac{\partial BCE}{\partial w} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i-y_i)x_i \]

5.4 Derivative with respect to bias

Similarly: \[ \frac{\partial z}{\partial b}=1 \]

Therefore: \[ \frac{\partial L}{\partial b} = (\hat y-y)\times1 \]

For the entire dataset: \[ \boxed{ \frac{\partial BCE}{\partial b} = \frac{1}{n}\sum_{i=1}^{n} (\hat y_i-y_i) } \]

We now have both gradients!

Learning Rate \(\alpha\)

We need a learning rate to control how much the parameters change during each iteration.

We represent it using: \[ \alpha \]

For our experiment, we'll use the following, just for the simplification of our calculation: \[ \boxed{\alpha=0.1} \]

This means each parameter update will be 0.1 times its corresponding gradient.

A small learning rate produces smaller updates, whereas a large learning rate produces larger updates.

Gradient Updation Rule

Now let's combine our mathematical derivations.

Our weight update equation: \[ \boxed{ w_{new}=w_{old}- \alpha\frac{\partial BCE}{\partial w} } \]

Our bias update equation: \[ \boxed{ b_{new}=b_{old}- \alpha\frac{\partial BCE}{\partial b} } \]

Substituting our gradients: \[ \boxed{ w_{new}=w_{old}- \frac{\alpha}{n} \sum(\hat y_i-y_i)x_i } \]

And: \[ \boxed{ b_{new}=b_{old}- \frac{\alpha}{n} \sum(\hat y_i-y_i) } \]

That's it! We now have the complete Gradient Descent equations for Logistic Regression.

Step 1: Calculate the initial loss

Our Binary Cross-Entropy formula: \[ BCE=-\frac{1}{3}\sum [y\log(\hat y)+(1-y)\log(1-\hat y)] \]

Substitute the values: \[ BCE=-\frac{1}{3}[ \log(0.5)+\log(0.5)+\log(0.5)] \] \[ =-\log(0.5) \] \[ \boxed{BCE=0.6931} \]

This is our initial loss.

Step 2: Calculate the weight gradient

\[ \frac{\partial BCE}{\partial w} = \frac{1}{3}\sum(\hat y-y)x \]

Substitute our observations: \[ =\frac{1}{3}[ (0.5-0)(1) +(0.5-0)(2) +(0.5-1)(4)] \] \[ =\frac{1}{3}[0.5+1-2] \] \[ =\frac{-0.5}{3} \] \[ \boxed{-0.1667} \]

Step 3: Calculate the bias gradient

\[ \frac{\partial BCE}{\partial b} = \frac{1}{3}\sum(\hat y-y) \] \[ =\frac{1}{3}[ (0.5-0)+(0.5-0)+(0.5-1)] \] \[ =\frac{1}{3}[0.5+0.5-0.5] \] \[ \boxed{0.1667} \]

Step 4: Update our parameters

Now apply the Gradient Descent update equations.

Weight: \[ w_{new}=0-0.1(-0.1667) \] \[ \boxed{w=0.0167} \]

Bias: \[ b_{new}=0-0.1(0.1667) \] \[ \boxed{b=-0.0167} \]

First update completed.

Our new model becomes: \[ \boxed{z=0.0167x-0.0167} \]

Notice that our weight increased while our bias decreased.

This is how Gradient Descent adjusts the parameters to reduce the loss.
